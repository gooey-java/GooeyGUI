GooeyGUI

Windows, buttons and widgets without wrestling Swing.

Build real desktop apps with simple, object-oriented Java. GooeyGUI is built on Swing but hides the complicated parts.

Read the docs Get started

Download GooeyGUI.jar and GooeyGUI-sources.jar. Runs on Java 17 or newer.

What’s in the cup

  • Real components, simple code

    Windows, buttons, text fields, checkboxes, sliders, dropdowns, images and tabs, each placed at an (x, y) you choose.

  • Run your method on a click

    Hand a button this::addOne and GooeyGUI runs your method every time it’s clicked.

  • Errors in plain English

    Use a component the wrong way and GooeyGUI explains the problem, how to fix it, and which line of your code caused it.

Your first sip

A counter that goes up every time you click.

import gooeygui.*;

public class CounterApp {
    private int count;
    private Label countLabel;

    public CounterApp() {
        Window window = new Window("Counter", 300, 200);
        countLabel = new Label("Count: 0", 100, 40, 100, 30);
        Button addButton = new Button("Add 1", 100, 90, 100, 30, this::addOne);
        window.addComponent(countLabel);
        window.addComponent(addButton);
    }

    public void addOne() {
        count++;
        countLabel.setText("Count: " + count);
    }

    public static void main(String[] args) {
        new CounterApp();
    }
}

Get started in three sips

  1. Grab the jars

    Download GooeyGUI.jar and GooeyGUI-sources.jar.

  2. Drop them in lib

    Put both jars in your project’s lib folder. VS Code shows the docs when you hover over GooeyGUI code.

  3. Import and run

    Add import gooeygui.*; at the top of your file, write your code and hit Run.
